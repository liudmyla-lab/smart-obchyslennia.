# SMART-Обчислення

Початковий вебпроєкт платформи формування обчислювальних навичок учнів 1 класу.

## Що включено
- Next.js вебінтерфейс українською мовою
- Вхід і реєстрація через Supabase Auth
- Ролі вчителя й учня (зчитуються з таблиці `profiles`)
- П'ять навчальних модулів і демонстраційний набір завдань
- Запис спроб до бази даних
- SQL-схема, таблиці та базові RLS-політики

## Запуск локально
1. Встановіть Node.js 20 або новішу версію.
2. Створіть проєкт Supabase.
3. У Supabase SQL Editor виконайте `supabase/schema.sql`.
4. Скопіюйте `.env.example` у `.env.local` і додайте URL та anon key вашого Supabase-проєкту.
5. У терміналі:
   ```bash
   npm install
   npm run dev
   ```
6. Відкрийте http://localhost:3000

## Важливі кроки перед реальною експлуатацією
Це стартовий код, а не вже розгорнутий публічний сайт. Перед використанням із дітьми потрібно:
- налаштувати серверне створення профілів і запрошення учнів учителем;
- додати безпечний процес видачі учнівських логінів/паролів або кодів доступу;
- завершити RLS-політики та перевірити їх тестами з різними ролями;
- додати серверну перевірку правильних відповідей (не довіряти відповіді, надісланій браузером);
- додати класні зв'язки, керування учнями, видалення/експорт даних;
- налаштувати резервне копіювання, політику приватності та мінімізацію персональних даних дітей;
- заповнити бібліотеку повним набором перевірених завдань і авторських ілюстрацій.

## Створення першого профілю
Після реєстрації адміністратор має створити рядок у `profiles` з тим самим UUID користувача з `auth.users`, повним ім'ям і роллю. Не надавайте дітям доступ до SQL Editor чи ключів Supabase.

## Розгортання
Рекомендований варіант — Vercel для Next.js та Supabase для бази даних. Додайте ті самі змінні середовища у Vercel Project Settings. Налаштуйте домен і redirect URLs у Supabase Auth.

## Дані дітей
Не використовуйте справжні ПІБ дітей на етапі тестування. Для продуктивного запуску отримайте необхідні погодження закладу/батьків, визначте строки зберігання та порядок доступу до даних.
